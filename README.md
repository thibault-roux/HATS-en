# HATS-en

**HATS-en** is an English benchmark for evaluating ASR metrics against human judgments of transcript quality. It extends the [HATS](https://github.com/idiap/hats) side-by-side evaluation protocol to English.

The dataset is based on **LibriSpeech test-clean** and contains human preference judgments between ASR hypotheses generated by four ASR systems.

## Dataset

The main dataset is:

```text
data/hats-en-systems.csv
```

It contains **1,000 comparison triplets** from **2,620 LibriSpeech segments**, annotated by **119 participants**.

Each row contains:

| Column       | Description                    |
| ------------ | ------------------------------ |
| `batch`      | Annotation batch               |
| `triplet_id` | LibriSpeech segment identifier |
| `reference`  | Reference transcript           |
| `h1_text`    | Hypothesis 1                   |
| `h2_text`    | Hypothesis 2                   |
| `h1_votes`   | Votes for hypothesis 1         |
| `h2_votes`   | Votes for hypothesis 2         |
| `h1_system`  | System producing hypothesis 1  |
| `h2_system`  | System producing hypothesis 2  |

The four ASR systems are:

* `whisper-base`
* `googlesr`
* `wav2vec-ft-asr`
* `crdnn-rnnlm`

For the main analysis, only comparisons with **unanimous human preference** are used.

## Evaluation

HATS-en is used to compare automatic metrics with human preferences, including:

* **WER**
* **CER**
* **BERTScore**
* **SemDist**

For BERTScore and SemDist, different language models, layers, and pooling strategies are evaluated.

The main results show that **CER substantially outperforms WER in agreement with human judgments**, while several SemDist configurations achieve agreement comparable to or above CER.
